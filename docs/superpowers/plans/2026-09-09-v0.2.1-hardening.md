# V0.2.1 Official Source Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make official API, PDF, and static HTML evidence safely retrievable and traceable without changing V0.2 stages.

**Architecture:** Add centralized redaction, deterministic official-source adapters, bounded PDF extraction, content-quality gates, and fact/script eligibility checks. Keep the existing artifact-first pipeline and store every source asset under `source_documents/`.

**Tech Stack:** Python 3.11+, pydantic, typer, pypdf, pytest

**Spec:** `docs/superpowers/specs/2026-09-09-v0.2.1-hardening-design.md`

## Global Constraints

- Do not change business stages or artifact ownership.
- Tavily snippets are never evidence.
- Never persist or print credentials, authentication headers, secret query parameters, payloads, or complete request objects.
- Official API parameters must be deterministically mapped; otherwise use PDF/HTML or fail.
- `verified` is the only status allowed for downstream factual assertions.
