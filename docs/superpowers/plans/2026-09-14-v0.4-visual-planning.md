# V0.4 Visual Planning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce durable semantic visual beats and an adapter-ready storyboard from a validated V0.3 script without rendering media.

**Architecture:** A deterministic visual planning provider proposes semantic beats, a storyboard assembler converts beats into explicit renderer instructions and stable object continuity, and local gates remain the final authority. ArtifactRegistry owns persistence and stale propagation.

**Tech Stack:** Python 3.11+, Pydantic 2, Typer, pytest.

**Spec:** `docs/superpowers/specs/2026-09-14-v0.4-visual-planning-design.md`

## Global Constraints

- `visual_beats.json` is renderer-agnostic.
- `storyboard.json` contains render directives and cross-beat continuity.
- All factual visible content is traceable to script sentences and allowed claims.
- Timing is estimated and relative; no real audio timestamps are created.
- No image, TTS, renderer, or MP4 generation.
