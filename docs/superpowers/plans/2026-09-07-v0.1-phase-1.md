# V0.1 Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic, resumable CLI that ingests local or pasted text and generates `source.md`, `questions.json`, `research.md`, and `run.json`.

**Architecture:** A filesystem-backed pipeline uses typed models, atomic artifact writes, content hashes, and injected analysis providers. The CLI is a thin adapter over independently testable ingest and analyze stages.

**Tech Stack:** Python 3.11+, Typer, Pydantic 2, pytest

**Spec:** `docs/superpowers/specs/2026-09-07-v0.1-phase-1-design.md`

## Global Constraints

- Implement only V0.1 Phase 1.
- Support `.txt`, `.md`, `--text`, and `--stdin`; URL fetching is out of scope.
- Persist every successful intermediate artifact and stage status.
- Reuse valid outputs by default; replace them only with explicit `--force`.
- Use only a deterministic mock provider; do not call a real model or network service.
- Do not modify or merge into `main`.
