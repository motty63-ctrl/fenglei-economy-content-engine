# V0.3 Content Planning and Script Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate, score, select, and persist original content angles and a linted 60–90 second Chinese economic video script from V0.2.1 verified research.

**Architecture:** A provider produces typed creative proposals while local policy constructs the fact whitelist, computes scores, validates originality and factual traceability, and controls artifact validity. Three independently rerunnable owner stages persist `angles.json`, `angle.md`, and `script.md` through the existing artifact registry.

**Tech Stack:** Python 3.11+, Pydantic 2, Typer, pytest; no storyboard, TTS, video, UI, automation, or new model-vendor SDK.

**Spec:** `docs/superpowers/specs/2026-09-09-v0.3-content-script-design.md`

## Global Constraints

- Existing V0.1–V0.2.1 stage behavior and artifact ownership must remain unchanged.
- Only verified facts with `allowed_downstream=true` may be asserted as settled facts.
- Unverified claims are forbidden; conflicted claims are forbidden as determinate assertions.
- Model output cannot mark artifacts valid or override locally computed policy fields.
- The provider never receives the `source.md` body.
- At least three materially different angles are required for the acceptance topic.
- `script.md` is valid only after every hard quality gate passes.
- Every stage remains independently rerunnable and uses hash-based stale propagation.
- Provider and stage errors use the existing secret-redaction boundary.

```python
class ScriptSentence(BaseModel):
    sentence_id: str
    section: Literal["hook", "phenomenon", "mechanism", "core_judgment"]
    sentence_type: Literal["verified_fact", "explanation", "interpretation", "analogy"]
    text: str = Field(min_length=1)
    claim_ids: list[str] = Field(default_factory=list)

    @model_validator(mode="after")
    def claims_match_type(self):
        if self.sentence_type == "verified_fact" and not self.claim_ids:
            raise ValueError("verified_fact requires claim_ids")
        if self.sentence_type != "verified_fact" and self.claim_ids:
            raise ValueError("non-factual sentence cannot claim external support")
        return self
```

```python
    return tuple(ScriptReadyClaim.from_claim(c) for c in facts["claims"]
                 if is_script_ready(c) and c.get("claim_type") == "fact"
```

```python
def estimate_seconds(sentences: Sequence[ScriptSentence]) -> float:
    spoken = strip_markdown_and_claim_markers("".join(s.text for s in sentences))
    return len(spoken) / 4.0

def render_fact(sentence: ScriptSentence) -> str:
    refs = "".join(f"〔claim:{claim_id}〕" for claim_id in sentence.claim_ids)
    return f"{sentence.text}{refs}"
```

The lint result contains `passed`, `estimated_duration_seconds`, `spoken_character_count`, and typed issues. A `Decimal.quantize` helper validates rounding only when metric, country, and year match across eligible observations. Rendering raises if `passed` is false.
