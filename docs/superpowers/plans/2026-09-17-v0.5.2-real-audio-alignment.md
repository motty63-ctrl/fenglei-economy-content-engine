# V0.5.2 Real Audio Alignment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a SHA-bound, human-reviewed, real sentence-level alignment for the approved GDP WAV without running upstream generation or downstream rendering.

**Architecture:** Keep the provider-neutral `AlignmentProvider` boundary. An opt-in local WhisperX adapter returns measured candidate spans and acoustic scores; deterministic matching and structural gates independently validate them. The 14-sentence GDP canary is manually labeled and reviewed before final `alignment.json` promotion.

**Tech Stack:** Python 3.11+, Pydantic, pytest; optional isolated local WhisperX/PyTorch/Chinese alignment and ASR models on Windows.

**Spec:** `docs/superpowers/specs/2026-09-17-v0.5.2-real-audio-alignment-design.md`

## Global Constraints

- Never rerun narration, research, factcheck, angles, script, storyboard, timeline, renderer, or MP4 during V0.5.2 alignment work.
- No fake/deterministic/character-count fallback in production. No diarization. ASR never edits the approved text.
- `original_text` and `narration_text` remain unchanged; normalized forms are matching-only and rule-versioned.
- All candidate/review/final records bind the *current* approved audio SHA and invalidate on upstream hash change.
- No permanent `0.85` threshold for uncalibrated acoustic scores. Structural gates always fail closed. The first GDP threshold requires all 14 human-labeled boundaries and explicit, scoped review.
- WhisperX and model downloads are opt-in, isolated from default offline tests; do not introduce a paid cloud API.

```python
def test_spoken_number_normalizes_without_changing_value():
    assert normalize_alignment_text("二〇二四年 G D P 增速百分之二点八。") == "2024年gdp增速2.8%"
    assert normalize_alignment_text("2024年GDP增速2.9%") != "2024年gdp增速2.8%"
```
