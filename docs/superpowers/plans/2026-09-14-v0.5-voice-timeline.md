# V0.5 TDD Implementation Plan

1. Extend the artifact graph and multi-output stage runner for V0.5 files, binary audio, and directory artifacts. Test ownership, hashing, stale propagation, and retry-safe writes first.
2. Define strict narration/audio/alignment/timeline models. Test schema boundaries and integer timing constraints.
3. Implement reversible narration normalization. Test abbreviations, institutions, years, percentages, numeric invariance, and semantic rejection.
4. Define separate narration and alignment provider protocols. Implement deterministic fake providers and canonical WAV validation. Test invalid codec, channels, sample rate, and empty audio.
5. Implement alignment validation and optional fallback. Test full coverage, monotonicity, overlap, bounds, audio-end equality, low confidence, and resume behavior.
6. Compile sentence-derived beat and scene timings. Test that V0.4 estimates are reference-only and that gaps retain the prior canvas.
7. Translate valid storyboard/timeline inputs into a Nikola project without semantic generation. Test provenance, audio hash, unsupported directives, stable object IDs, and renderer manifest output.
8. Implement fake and opt-in local renderer probes. Test temporary-output cleanup, capability failures, and the no-final-MP4 invariant.
9. Wire the resumable CLI pipeline. Test stop/force behavior, default reuse, provider configuration changes, failure recovery, and end-to-end fake execution.
10. Run the complete suite, run the accepted GDP artifact through the deterministic pipeline, and run the real local Nikola dry-run only when its explicit runtime dependencies are configured.
